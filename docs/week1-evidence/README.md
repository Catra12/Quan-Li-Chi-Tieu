# Week 1 Evidence - DevOps Project

Thư mục này dùng để lưu trữ minh chứng (screenshots, log files, kết quả kiểm thử) cho Tuần 1 của đồ án DevOps.

## Nội dung minh chứng cần nộp:
1. **Khởi chạy ứng dụng**:
   - Ảnh chụp màn hình ứng dụng chạy trên trình duyệt (`http://localhost:3000`).
   - Ảnh chụp màn hình kiểm tra endpoint `/health` (`http://localhost:3000/health`).
2. **Thao tác dữ liệu**:
   - Ảnh chụp màn hình form thêm chi tiêu thành công.
   - Ảnh chụp màn hình danh sách chi tiêu và tổng tiền cập nhật.
   - Ảnh chụp màn hình thao tác xóa chi tiêu.
3. **Cơ sở dữ liệu MongoDB**:
   - Ảnh chụp dữ liệu trong MongoDB Compass hoặc `mongosh` trên database `quanlychitieu`.
4. **Git logs**:
   - Lịch sử commit thể hiện việc khởi tạo cấu trúc dự án.
